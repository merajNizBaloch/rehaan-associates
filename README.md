# Rehan Consultants — Complete Visual Redesign

This version intentionally abandons the previous architecture-portfolio composition.

Visual concept: **site report / field journal / engineering index**.

Core states:
- Field: warm paper, terrain, terracotta, sand, green, engineering blue.
- Night: dark site-report aesthetic.
- Blueprint: drafting-paper experience with technical grid, red revision marks, scale notation and drawing-set language.

Desktop interaction:
- Custom brick cursor.
- Interactive survey canvas.

Mobile interaction:
- Device tilt is read where supported.

Run:

```bash
npm install
npm run dev
```
